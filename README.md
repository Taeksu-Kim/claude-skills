# claude-skills

Claude Code 스킬 배포본. 쓰려면 이 레포를 클론하고, 레포 폴더에서 Claude Code를 실행한다
(스킬은 `.claude/skills/` 아래). 다른 프로젝트에서 쓰려면 스킬 폴더를 그 프로젝트의 `.claude/skills/`에 복사한다.

| 스킬 | 하는 일 |
|---|---|
| `skill-craft` | 스킬 만들기·고치기·검토 (판단 지점 나누기, 사용자 자료·실패로 전문성 채우기, 실패 기록으로 키우기) |
| `ui-design` | 화면(UI)·UX 작업의 진입점 — 작업 종류별로 필요한 지침만 단계적으로 읽게 함 |
| `ko-writing` | 한국어 글을 AI 티 없이 쓰고 고치기 — 쓸 때는 재료 고르기, 고칠 때는 걸리는 곳만. 패턴 목록은 humanize-ko(MIT) 기반, 출처는 `THIRD_PARTY.md` |

## 운영 (작업본 → 배포본)
- 작업본은 작성자의 로컬 프로젝트에 있다. 고치기·실험은 거기서 하고, 이 레포는 직접 고치지 않는다.
- 작업본이 써 보고 괜찮으면 사용자가 "반영해"라고 할 때 이 레포로 복사하고 커밋한다 — 변경 목록과 `NOTES.md`의 새 기록을 먼저 보여 준다.
- 반영할 때 사용자 발언 인용은 두되, 이 컴퓨터 경로·다른 프로젝트 이름·채널을 특정할 수 있는 내용(편 번호·제목·성과 수치)은 일반 이름으로 바꾼다.

## 기록
각 스킬의 `NOTES.md`에 결정([D])·실패([F])·주의([C])와 만든 과정(규칙 ↔ 출처)이 있다. `skill-craft/experiments/`는 스킬을 실제로 돌려
있이/없이 비교한 시험 기록이다 — 시행착오를 남기려고 공개한다. 수치는 그 시험에서 잰 값(LLM 평가자 1명, 실행 1회).
