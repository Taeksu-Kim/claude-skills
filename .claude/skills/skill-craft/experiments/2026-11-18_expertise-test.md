- 2회차 새 빈 곳 중 "판단을 틀리게 함": ① 이상치 하나가 모든 막대를 가늘게(공통 눈금) ② 스스로 덧붙인 경고 문구의 오탐(구독 섞인 가맹점).
  ②는 경계표를 판정 문장에만 적용하고 **스스로 만든 경고·자동 표시에는 적용 안 한** 것 — 같은 계열의 빈 곳.
- 평가 2 결론: "비슷한 수준에서 강점이 다르다, 판정 신뢰성은 2회차가 한 단계 위". 시니어가 그대로 내놓을 수준은 둘 다 아님.
- 결정(사용자 "니 추천대로 하자"): 3회차 대신 2회차 빈 곳만 반영(ui-design D13) — 경계표를 덧붙인 경고까지·이상치 눈금, 포커스 링은 측정으로.
  3회차는 다음에 새 종류 화면(입력·편집)을 실제로 만들 때 그 작업을 사례로 (D27 조건).

# 전문성 루프 두 번째 — episode-concept (같은 날)

소재 얼죽아(지난 시험 소재와 다름), 기준 13개 고정(지난 시험 1~12 + 13 가설·확인). 서브에이전트 5개 [측정]:
스킬 없이 120,121 / v3 112,493 / 평가 122,939 / 반영 후 124,646 / 평가 126,765 = 606,964.

- 1회차 (스킬 없이 vs v3): 같은 각도로 수렴. v3가 겹침·끝까지 볼 구성·채널 근거·가설에서 앞섬, 스킬 없이는 대본 실행 명세·TTS 동음에서 앞섬.
  공통 빈 곳 → episode-concept F12 (출처 없는 일본 쪽 전제를 반전 축으로, 시리즈 꼬리로 짐작되는 두 갈래, 낡은 수치, TTS 동음).
- 2회차 (v3 vs 반영 후): **비슷한 수준, 강점이 다름 — 나아지지 않음(수렴)**. F12 줄은 결과를 바꿨다(최신 출처·일본 쪽 조사·TTS·공개 시기).
  대신 "두 갈래 대신 何割" 쪽으로 옮기며 1회차의 구성 강점(첫 화면 그림 대비·틀 비겹침·뒤쪽 보상)을 잃고, 다른 모집단 숫자를 한 사슬로 이음.
  내가 넣은 "12시간 칸 없으면 모름" 줄이 채널 근거를 버리게 함 → F13으로 바로 고침.

**skill-craft에 주는 것 (판단 자료)**
1. 고친 줄이 지난 회차의 강점을 밀어낼 수 있다 — 반영할 때 평가자가 꼽은 강점이 어느 줄에서 왔는지 적고 새 줄과 부딪치지 않나 본다.
   (ui-design 루프에서는 안 일어났고, 여기서는 일어남. 규칙이 구성 선택을 바꾸는 스킬일수록 위험)
2. 이름 가림 정리(스크립트로 F번호·단계 번호 지우기)가 「(1a, )」 같은 잔해를 남겨 평가자가 결함으로 잡음 — 가림은 문장째 바꾸고 잔해를 grep.
3. 나가는 조건 "수렴"이 실제로 걸린 첫 사례. 3회차 조건(D27)의 새 고위험 빈 곳(다른 모집단 숫자 사슬)은 있으나, 다른 사례 + 승인 필요.
