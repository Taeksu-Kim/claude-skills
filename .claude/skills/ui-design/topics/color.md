# 색 — 대표색을 고르지 말고 체계를 만든다

**읽는 때**: 새 화면·재디자인에서 색을 정할 때, 사용자가 "색 조합이 마음에 안 든다"고 할 때 (`../stages/1-shape.md` 시각 방향,
`../stages/2-build.md` 조건표). 도구: `../scripts/palette.py` (OKLCH 단계·역할·대비·면적).
**왜 있나 (D18)**: 대표색 hex 몇 개를 눈대중으로 바꾼 후보 3개가 실제 화면에서 셸 말고는 구분되지 않았고, 바탕(크림 H≈99)·글자 회색(H≈150)·
주 색(H≈171)이 서로 다른 계열이라 "조합이 안 맞는다"는 판정을 받았다. 잘 만든 팀은 색을 단계로 만들고 역할을 그 단계에서 고른다.

## 근거 [측정 2026-11-20, `palette.py info`]
- 토스 TDS 회색 50~900: 색상각 H 248~258 = 토스 파랑 H 258 — 회색을 주 색 계열로 아주 옅게 물들임. 채도 0.002(바탕) → 0.028(가운데) → 0.020(가장 어두운).
- 당근 SEED 회색 00~1000: H 248~269 차가운 중립 — 주 색(당근 주황)과 다른 계열로 두고 주 색만 따뜻하게.
- 둘 다 회색 10단계 이상, 색마다 단계 10개 (TDS `grey50~900`, SEED `gray-00~1000`). Primer: 바탕 0~5 · 선 7~8 · 글자 9~10 단계를 역할로.

## 순서
1. **축을 먼저 고른다 — 후보는 이 축에서 가른다.** 도구 화면은 면적의 70% 안팎이 바탕·면이라([측정] `palette.py area`, 논문 분석 프로젝트 2026-11-20)
   대표색만 바꾸면 후보가 셸 말고는 같아 보인다. 화면 전체를 바꾸는 축:
   - 회색 온도: 주 색 계열로 물들임(TDS) / 차가운 중립(SEED) / 따뜻한 중립 — 크림(H 80~100, 채도 0.006 이상) + 세리프 제목은 AI 기본값 1번(`direction.md` §3), 이유가 있을 때만
   - 셸 처리: 진한 주 색 칸 / 밝은 칸 + 선택만 주 색 / 진한 중립(흑연) 칸
   - 주 색: 색상각·채도 (사용자가 정한 주 색이 있으면 그대로 — 이 축은 건너뛴다)
   - 바탕과 면의 밝기 차: 지면이 떠 보이게 하려면 바탕 단계 1~2 / 면 흰색, 평평하게는 같은 단계 + 선
   후보끼리 축 둘 이상이 달라야 한다.
2. **단계로 만든다**: `palette.py scale --hue H --chroma C --neutral-hue H2 --neutral-chroma c` — 주 색 1벌과 회색 1벌, 밝기 단계 0~10.
   회색을 물들이면 `--neutral-hue`를 주 색 H로, 채도는 0.010~0.016 (가운데 단계 기준).
3. **역할은 단계에서 고른다**: `palette.py roles … --css` — 바탕·면·선·메타 글자·보조 글자·본문·주 색·옅은 주 색을 단계에서 뽑고 역할 쌍
   대비를 함께 낸다. 메타 글자는 바탕에서 4.5:1 이상(모자라면 도구가 한 단계 진하게). hex를 손으로 고쳐 넣지 않는다 — 단계를 바꾼다.
4. **의미색**(성공·경고·오류)은 주 색과 같은 밝기·채도 대에서 색상각만 바꿔 만든다 (`from_oklch`). 따로 고르면 한 화면에서 따로 논다.
5. **실제 화면에 입혀 비교한다**: 후보마다 CSS 변수만 바꿔 같은 화면을 캡처하고 한 장에 붙인다 (견본 색 조각으로 고르지 않는다).
   그 화면에서 `palette.py area`로 색 면적을 적는다 — 주 색이 몇 %인지, 바탕과 면이 구분되는지(같은 덩어리로 묶이면 지면이 안 뜬다).
6. **사용자가 고른다** — 시각 방향은 사용자 몫 (SKILL §2). 후보마다 "이런 경우면 이쪽"을 한 줄씩.

## 검수 (후보를 보이기 전)
- 후보끼리 1의 축 중 둘 이상이 다른가 → 아니면 1로
- 회색과 주 색의 관계(같은 계열로 물들임 / 일부러 다른 계열)를 한 문장으로 말할 수 있나 → 못 하면 2로
- 역할 쌍 대비 미달이 hover 같은 잠깐 보이는 면 말고 없나 (`roles` 출력) → 있으면 3으로
- 사용자가 정한 색 결정(`CLAUDE.md`·메모리)을 지켰나
