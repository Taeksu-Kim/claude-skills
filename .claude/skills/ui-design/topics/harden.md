# 견고하게 (harden) — 완벽하지 않은 데이터·네트워크·입력에서

**읽는 때**: 입력·가져오기·목록·외부 호출이 있는 화면을 만들거나, "이상한 데이터에서 깨진다"는 문제.
**다음**: 각 경우를 `../stages/6-verify.md` 의 브라우저 점검 스크립트에 **실제 케이스로 추가**한다.

## 먼저 시험할 것

| 범주 | 케이스 |
|---|---|
| 극단 입력 | 아주 긴 이름(100자+), 빈 값, 한 글자, 이모지, 큰 수(억·조), 1000+ 행, 50+ 선택지 |
| 오류 | 네트워크 끊김·느림·시간초과, 400/401/403/404/429/500, 검증 실패, 권한 없음, 동시 작업 |
| 언어·형식 | 한글·한자·이모지 혼합, 날짜·숫자·통화 형식 |
| 반복·순서 | 같은 입력 두 번, 빠른 연속 클릭(10번), 새로고침·뒤로가기 중간, 여러 탭 |

## 처리 방법

- **넘침**: 한 줄 말줄임 / 여러 줄 `line-clamp` / 줄바꿈 `overflow-wrap`. flex·grid 자식은 `min-width: 0`.
  텍스트 컨테이너에 고정 폭 금지. 200% 확대에서 컨테이너가 글자와 함께 늘어나는지.
- **네트워크 오류**: 무슨 일인지 + 다시 시도 버튼. 컴포넌트 하나의 오류로 전체 화면을 막지 않는다.
- **폼 오류**: 필드 옆에 구체적으로, 입력값은 보존, 불필요하게 제출을 막지 않는다. 서버 검증은 항상 (클라이언트만 믿지 않는다).
- **API 상태별**: 400 검증 오류 표시 / 401 로그인 / 403 권한 설명 / 404 없음 상태 / 429 잠시 후 / 500 일반 오류 + 다음 행동.
- **빈 상태·로딩**: 첫 로드·페이지 넘김·새로고침을 구분. 무엇을 불러오는지 적는다. 오래 걸리면 예상 시간.
- **대량 데이터**: 페이지 나눔 또는 가상 스크롤, 검색·필터. 1만 건을 한 번에 그리지 않는다.
- **동시 작업**: 요청 중 버튼 비활성(중복 제출 방지), 경쟁 상태 처리, 낙관적 갱신이면 실패 시 되돌리기.
- **끊긴 제스처**(드래그·슬라이더): 두 번째 손가락, `pointercancel`, `lostpointercapture`, 창 밖에서 놓기, 창 전환 —
  각각 후 드래그 상태를 정리하고, 다음 조작이 새로고침 없이 동작해야 한다.
- **권한**: 볼 수 없음 / 편집 불가 / 읽기 전용을 이유와 함께 표시.
- **입력 제약**: `maxlength`·`pattern`·`required` + 조건을 미리 보여주는 도움말(`aria-describedby`).
- **성능**: 검색 입력 디바운스(~300ms), 스크롤 처리 스로틀. 화면을 떠날 때 리스너·타이머·대기 요청 정리.
- **접근성 내구성**: 키보드만으로 모든 기능, 모달 포커스 관리, 동적 변화 알림(`aria-live`), 색 외 단서.

## 피할 것
완벽한 입력 가정, "오류가 발생했습니다" 같은 일반 메시지, 클라이언트 검증만 신뢰, 텍스트에 고정 폭, 오프라인 무시.

## 보고
