# 스타일 어휘 (선택 참고)

**읽는 때**: 방향 후보를 사용자와 이야기할 때 공통 이름이 필요하면. 고르는 목록이 아니라 **말을 맞추는 사전**이다.
여기서 하나를 골라 그대로 적용하지 않는다 — 주제에서 출발한 방향(`direction.md`)을 설명하는 데 쓴다.

| 이름 | 특징 | 잘 맞는 곳 |
|---|---|---|
| 스위스 미니멀 | 격자, 넓은 여백, 강한 대비, 기능 중심 | 도구·문서·업무용 |
| 플랫 | 그림자 없는 2D, 색면, 단순한 아이콘 | 웹앱 전반, 빠른 MVP |
| 데이터 밀집 대시보드 | 작은 여백, 표·차트·지표가 한 화면에 | 분석·운영 도구 |
| 임원용 요약 | 큰 핵심 지표 몇 개, 세부는 숨김 | 의사결정 요약 화면 |
| 드릴다운 | 요약 → 클릭으로 세부 계층 | 분석 화면 |
| 벤토 그리드 | 크기 다른 모듈 카드의 비대칭 격자 | 소개 페이지 기능 요약, 개인 대시보드 |
| 에디토리얼·잡지 | 비대칭 격자, 큰 제목, 인용, 단 구성 | 리포트·블로그·긴 글 |
| 종이·E-ink | 무광, 차분, 높은 대비, 질감 | 읽기 중심 |
| 접근성 우선 | 큰 글자, 강한 대비, 명확한 포커스 | 공공·누구나 쓰는 화면 |
| 소프트 UI | 부드러운 그림자, 둥근 모서리, 낮은 대비 (대비 주의) | 생활·건강 앱 |
| 글래스모피즘 | 반투명·블러 면 위 레이어 (대비·성능 주의) | 소개 페이지 장식 요소 |
| 다크 OLED | 깊은 검정 바탕, 밝은 강조 | 야간 사용, 미디어 |
| 브루탈리즘 | 날것, 기본 글꼴, 강한 대비, 의도적 투박함 | 개성 강한 포트폴리오 |
| 네오브루탈리즘 | 굵은 검정 테두리, 원색, 딱딱한 그림자 | 발랄한 브랜드·스타트업 |
| 클레이모피즘 | 말랑한 3D, 두꺼운 둥근 형태 | 교육·아동·놀이 |
| 오로라·그라데이션 메시 | 부드럽게 섞이는 큰 그라데이션 | 소개 페이지 첫 화면 |
| 과장된 미니멀 | 거대한 글자, 큰 여백, 극단 대비 | 패션·건축·포트폴리오 |
| 키네틱 타이포 | 움직이는 글자 | 소개 첫 화면, 캠페인 |
| 패럴랙스 스토리텔링 | 스크롤 따라 겹겹이 진행 | 브랜드 이야기 (도구엔 금지) |
| 레트로 퓨처·사이버펑크 | 네온, 글리치, HUD | 게임·엔터테인먼트 |
| 유기적·자연 | 흙색, 둥근 형태, 자연 재료 | 웰니스·친환경 |
| 손그림·스케치 | 흔들리는 선, 손글씨 | 저충실 시안, 아동 |
| 히어로 중심 | 큰 첫 화면, 강한 제목·행동 | 제품 출시 랜딩 |
| 전환 최적화 | 단일 행동, 폼 중심, 군더더기 없음 | 가입·신청 페이지 |
| 신뢰·권위 | 인증·자격·사례 전면 | 금융·의료 소개 |
| 인터랙티브 데모 | 실제 제품 화면을 페이지에서 조작 | 도구 소개 |
